# 参考資料

- [rsshogi](https://github.com/nyoki-mtl/rsshogi)：盤面、合法手、SFEN。bitboardなど盤面表現の解説もこちらのドキュメントにある
- [rsshogi-usi](https://github.com/nyoki-mtl/rsshogi-usi)：USIコマンドの表現、解析、整形
- [rsshogi-csa](https://github.com/nyoki-mtl/rsshogi-csa)：CSA中継
- [ShogiArena](https://github.com/nyoki-mtl/ShogiArena)：対局、SPSA、SPRT、ダッシュボード

## 探索アルゴリズム

- [Claude E. Shannon, “Programming a Computer for Playing Chess”](https://doi.org/10.1080/14786445008521796)：ゲーム木探索を計算機チェスへ適用した初期の論文
- [Donald E. Knuth and Ronald W. Moore, “An Analysis of Alpha-Beta Pruning”](https://www.sciencedirect.com/science/article/pii/0004370275900193)：alpha-beta法の解析
- [Chess Programming Wiki](https://www.chessprogramming.org/Main_Page)：探索、評価、手の並べ替えなどの用語別資料
