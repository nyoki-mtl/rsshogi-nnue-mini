# 評価関数

このエンジンは、`.rsnn`形式の評価関数を使う。
[Release](https://github.com/nyoki-mtl/rsshogi-nnue-mini/releases/tag/eval-2026.09.30)から入手し、[セットアップ](getting-started.md)の手順で実行ファイルに内蔵する。

## 評価の仕組み

駒配置と持ち駒から、双方の視点のHalfKA_hm特徴を作る。
512幅の量子化NNUEで計算し、玉と駒の関係を表すPSQTの値も加える。
出力層は局面の進行度に応じて8種類から選ぶ。

探索中は、着手のたびに全特徴を計算し直さない。
動いた駒と持ち駒の変化をaccumulatorに反映し、指し手を戻すときは評価状態も戻す。
玉が動いて特徴の基準が変わる場合は、その玉位置で記録した状態を使って作り直す。

推論は整数演算で行い、AVX2、NEON、scalarの経路を備える。
どの経路も同じ評価値を返すように実装している。
探索に渡す評価値は±31,753に収め、詰みの点数と区別する。
